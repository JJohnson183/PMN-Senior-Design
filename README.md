# PMN-Senior-Design

CS 4900 senior design project for Public Media Network (PMN). It reads public meeting info
(date, time, location, title and agenda link) from municipality websites and agenda PDFs, for
a meeting calendar on PMN's WordPress site.

## Folders

| Folder | What it is |
|---|---|
| [`backend_api`](backend_api/README.md) | Python code that finds upcoming meetings and reads their agenda PDFs |

Setup, running and tests are in each folder's README. Run commands from inside that folder.
